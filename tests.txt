Тесты для программы mathtool.py
Проверка решения уравнений A*x^2 + B*x + C = 0
Таблица тестов:
1. A=1, B=-3, C=2
   Ожидаемо: Уравнение квадратное, D = 1, x1 = 2.000, x2 = 1.000
2. A=1, B=-2, C=1
   Ожидаемо: Уравнение квадратное, D = 0, x = 1.000
3. A=1, B=0, C=5
   Ожидаемо: Уравнение квадратное, D = -20, Действительных корней нет
4. A=0, B=2, C=-4
   Ожидаемо: Уравнение линейное, x = 2.000
5. A=0, B=0, C=0
   Ожидаемо: ОШИБКА: это не уравнение, код возврата 1
6. A=0, B=0, C=7
   Ожидаемо: ОШИБКА: это не уравнение, код возврата 1
7. A=abc, B=1, C=1
   Ожидаемо: ОШИБКА: коэффициент не является числом, код возврата 1
8. A=50000, B=1, C=1
   Ожидаемо: ОШИБКА: значение слишком большое, код возврата 1
Тесты для командной строки:
- python mathtool.py
  Ожидаемо: вывод справки, код возврата 0
- python mathtool.py --help
  Ожидаемо: вывод справки, код возврата 0
- python mathtool.py solve
  Ожидаемо: программа спрашивает A, B, C с клавиатуры
- python mathtool.py solve -a 1 -b -3 -c 2
  Ожидаемо: Уравнение квадратное, D = 1, x1 = 2.000, x2 = 1.000
- python mathtool.py unknown
  Ожидаемо: ОШИБКА: неизвестная команда, код возврата 1
- python mathtool.py solve -a 1 -b 2
  Ожидаемо: ОШИБКА: неверный набор параметров, код возврата 1
